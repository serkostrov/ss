# Привязка каналов Telegram и Max к рабочей группе

Привязка: **Админ → Группы → [группа] → Чаты**.

Бот АПСС принимает **только посты из каналов** (не из обычных групп и не из лички).

## Как появляется канал в списке

1. Сначала запустите messenger и убедитесь, что webhook зарегистрирован (`Telegram webhook registered`).
2. Создайте **канал** в Telegram (не группу) / канал в Max.
3. Добавьте бота АПСС в канал **администратором** (после запуска worker).
4. В логах messenger должно появиться: `Telegram webhook received` с `my_chat_member` или `channel_post`.
5. Обновите форму привязки — канал появится в Select.

Альтернатива: опубликуйте любой пост в канале (где бот уже админ) — worker тоже добавит канал в каталог.

Если бот был добавлен **до** регистрации webhook — удалите бота из канала и добавьте снова, либо введите `chat_id` вручную (поле появляется, когда список пуст).

### Как узнать chat_id Telegram

- Перешлите пост из канала боту `@RawDataBot` / `@getidsbot`, либо посмотрите `chat.id` (часто `-100…`).

## Если список пуст и webhook «зарегистрирован»

1. Применена ли миграция `20260715000030_messenger_bot_channels.sql`?
2. В логах messenger при добавлении бота есть `Telegram webhook received`?
   - Нет → Telegram не достучался до `PUBLIC_WEBHOOK_BASE_URL` (проверьте `https://hooks…/health` и `getWebhookInfo` / `lastError` в логах старта).
   - Есть `unauthorized` → не совпадает `TELEGRAM_WEBHOOK_SECRET`.
3. Это канал, а не группа?

## Worker

- `GET /health`
- `POST /webhooks/telegram`
- `POST /webhooks/max`

После привязки посты из канала попадают в историю рабочей группы (админка и кабинет).
