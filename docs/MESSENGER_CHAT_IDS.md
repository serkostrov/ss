# Привязка каналов Telegram и Max к рабочей группе

Привязка: **Админ → Группы → [группа] → Чаты**.

Бот АПСС принимает **только посты из каналов**. Личные сообщения и обычные группы в историю не пишутся.

## Как появляется канал в списке

1. Добавьте бота АПСС в канал **администратором** (Telegram / Max).
2. Messenger worker получит событие membership (`my_chat_member` / `bot_added`) и запишет канал в каталог.
3. В форме привязки выберите канал из списка (ручной ввод ID больше не нужен).

Если список пуст — бот ещё не был добавлен в канал или worker не запущен / не зарегистрирован webhook.

## Worker

Сервис `apps/messenger` принимает webhooks:

- `POST /webhooks/telegram`
- `POST /webhooks/max`
- `GET /health`

Нужны переменные окружения из `.env.example`: токены ботов, секреты webhook, `PUBLIC_WEBHOOK_BASE_URL`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.

После привязки канала посты из него попадают в историю рабочей группы (админка и кабинет участника).
